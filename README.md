# Curso de Python - Hashtag Treinamento

Este repositório tem como objetivo organizar os conteúdos, lições, projetos e aulas do curso de Python que estou realizando no Hashtag Treinamento. Aqui você encontrará tudo o que foi aprendido ao longo do curso, incluindo exemplos de código, explicações, exercícios práticos e projetos desenvolvidos.

## Estrutura do Repositório

- **Conteúdos**: Material teórico, artigos e recursos de aprendizado.
- **Lições**: Exercícios e exemplos de código de cada módulo do curso.
- **Projetos**: Projetos práticos desenvolvidos durante o curso.
- **Aulas**: Anotações de aulas e explicações detalhadas sobre tópicos abordados.

## Como Usar

1. Clone este repositório em sua máquina local:

    ```bash
    git clone https://github.com/contateobrito/curso-python-hashtag.git
    ```

2. Navegue pelas pastas para encontrar o conteúdo que deseja estudar.

3. Execute os scripts Python e acompanhe os projetos para aprender com exemplos práticos.
